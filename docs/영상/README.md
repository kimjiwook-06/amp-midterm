# Demo video

`demo_1min.mp4` is a 60-second recording of actual browser interactions with the Flutter build and local json-server. It has no narration. Playback is slowed slightly from the original 54.64-second capture to allow reading. It is not a slideshow or a recording of a real AI service.

Flow: voice example → search result → photo location → information tab → found sheet → photo example → analysis loading → edit uncertain name → simulated save → loading/error/empty scenes → narrow layout.

The UI and mock behavior match the source. Screenshot evidence is in ../screenshots. Only the final MP4 is included; duplicate raw recordings were removed.
