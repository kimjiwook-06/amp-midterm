깨끗한 소스 검증은 실제 원격 GitHub clone이 아니라 당시 소스 압축본을 새 디렉터리에 풀어 검증한 것이다. 검증용 압축본과 임시 디렉터리는 저장소 정리 시 제거했다. GitHub 업로드·LMS 제출·발표는 하지 않았다. Android 기기 실행은 검증하지 않았으며 브라우저가 주 시연 환경이다.

## GitHub 제출용 정리
의존성·빌드 캐시, 템플릿 사본, 중복 압축본, 원본 녹화 파일과 일회성 생성 스크립트를 제거했다. Flutter 코드, 플랫폼 설정, 패키지 잠금 파일, 로컬 서버 데이터, 사진·폰트, 테스트, 문서와 최종 시연 영상은 유지했다. 정리 직전 analyze와 10개 테스트를 다시 통과했다. 첫 실행은 README의 설치·빌드 절차를 따른다.

1. Flutter 3.47의 ListTile/Material 검사: 카드 내부에 Material을 제공해 잉크 효과를 보장.
2. CheckboxListTile 내부 수정 버튼 접근성 병합: 별도 Row 자식 버튼으로 분리.
3. 모바일 NavigationBar/ActionChip의 접근성 역할을 tab/checkbox로 인식하도록 브라우저 검증 스크립트 수정.
