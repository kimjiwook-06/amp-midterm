# Local read-only mock server

Run `npm ci` then `npm start` here. json-server 0.17.4 is pinned to the course template. GET http://localhost:3000/items returns four Korean examples. CORS is enabled; non-read methods are rejected. Coordinates are fractions of the bundled image measured from its top-left. All data are fictional.

Android emulator: 10.0.2.2. Real devices: use API_BASE with the PC IP on the same network. Browser is the fully validated delivery target.
